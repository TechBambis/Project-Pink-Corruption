# Reporting a security issue

This is a development beta. Only the current `main` branch is maintained; there is no audited release or guaranteed response time. See [local service security](docs/LOCAL_SECURITY.md) for current protections and limits.

For the private beta, use a minimal, sanitized issue in this private repository to contact the maintainer. Other invited repository members can read it. Do not include credentials, private recordings, conversations or a working exploit against someone else's system. If more sensitive evidence is needed, agree on a private channel with the maintainer before sharing it.

If this repository becomes public, use GitHub's **Report a vulnerability** option when available. If that option is absent, request a private contact channel from [BambiOS](https://github.com/BambiOS) before sending technical details; do not publish the vulnerability in an issue. A dedicated reporting channel must be set up before a public launch.

Include the affected commit, operating system, a short description, the impact and minimal reproduction steps using dummy data.
