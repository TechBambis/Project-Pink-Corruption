# Linux x64 local AI alpha

This build extends the qualified packaging smoke with a bundled native llama runtime and a freshly frozen CPython speech service. Model data is installed separately through Setup. No developer virtual environment, model weights, credentials, user database or recordings are included in the application.

Build on native Linux x64: `npm ci`; create a clean `.runtime/alpha-freeze-env` with CPython 3.12.13 and install `packages/speech/desktop-build.lock`; acquire the checksum-pinned Ollama 0.35.1 Linux archive ; dependency sources are acquired and checksum-verified by the builder; then run `node scripts/desktop-alpha-build.mjs 0.1.0-alpha.N`. The builder refuses an existing version output, rebuilds the web UI and speech service, inventories the actual copied backend, and includes corresponding source from the dirty working tree. It does not publish anything. Exact pins, source digest and file hashes accompany each artifact.

Launch the AppImage or extracted tar outside the repository. FUSE-free extraction is supported by the AppImage's `--appimage-extract`, then `squashfs-root/AppRun`. Retain the Chromium sandbox; do not pass sandbox-disabling flags. Default private data location is `~/.config/bambi-local-alpha`; `--bambi-user-data=/absolute/path` selects an isolated profile. Ports default to 6969 (app), 6970 (model), 6971 (speech); `--bambi-port=N` selects three consecutive ports. Conflicts produce a visible failure without reusing or stopping another application's service.

Open **Setup**. Choose **Download and verify**, or **Choose verified data folder** to copy already obtained public files. Downloads use the pinned URLs, byte limits and SHA-256 in `config/desktop-alpha-models.json`. Files are staged individually and activated only after verification. Cancel removes the current partial while retaining verified files. Retry reuses those files. Select **Prepare local AI**, then open your companion and enable local AI. The 9B model retains its full 24576-token context and the existing prompt, voice blend, DSP, timing and cancellation protocols. English streaming microphone recognition runs through private process pipes. The default voice blend is regenerated from the verified upstream embeddings and checked against its existing fingerprint.

**Load offline sample** works before setup and after a setup failure. It uses the normal player, controls and visuals. **Audio Mute** silences app output. **Mic Mute** releases microphone capture. **End session** cancels current generation/output and releases capture; the prepared model may remain resident. **Quit**, Ctrl+Q or closing the last Linux window exits the app and its owned services. Second launch with the same profile focuses the existing window.

After successful setup, restart without network access. Startup verifies installed data before enabling AI; it does not download or load the model silently. Select Prepare or start an explicitly requested local conversation to load the model. Cache, logs and model data stay in the user profile; replacing the executable does not delete them. SQLite is private to your account but is not application-encrypted. Automatic updates and database downgrade compatibility are not qualified.

The renderer is sandboxed with context isolation and no Node integration. Its narrow native bridge only opens a model-data folder chooser from the main Setup page. Microphone permission is limited to audio capture from this app's own main frame; camera and other permissions remain denied. Renderer network requests stay on the app origin. The backend owns its private keyed model API and speech credential; credentials are never sent to the renderer. No cloud setup, device bridge, extension, imported-media transcription or hosted service is qualified by this artifact.

The build guide links a small prepared `studio-chimes.bambi.json` package for Studio import, preview, export and reimport. Studio drafts remain in memory: export before closing. Qualification records list actual import/preview/export/reimport evidence and any missing capability. Model-dependent generation and optional external services are separate from prepared playback.

Use the accompanying capability record for the exact tested artifact, runtime/source hashes, measured performance, reference hardware and known limits. Automated PCM/caption tests do not establish a physical speaker listening test. Virtual microphone capture does not establish physical microphone quality. Windows/macOS and a second physical Linux machine require separate qualification. The package is unsigned; checksums establish integrity against the reviewed copy, not publisher trust.
