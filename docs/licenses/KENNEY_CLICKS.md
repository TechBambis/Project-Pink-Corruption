# Kenney CC0 clicks

The selected `tick_main.wav` and `tick_sub.wav` derive from `web/audio/click1.ogg` and `click2.ogg` in [furrz/hypnospiral at the pinned revision](https://github.com/furrz/hypnospiral/tree/56a1acad9a3eed08d077e8d8293a8afbb7454d05/web/audio).

The [pinned README license section](https://github.com/furrz/hypnospiral/blob/56a1acad9a3eed08d077e8d8293a8afbb7454d05/README.md#license) attributes the sounds in `web/audio` to [Kenney](https://kenney.nl) under CC0. The repository's MIT license covers its source code separately.

The import retains verified Git blob hashes, SHA-256 hashes, attribution and processing details in `assets/sounds/tick-clicks.json`. WAV derivatives are mono 44.1 kHz PCM16 with short edge fades, peak −12 dBFS, and trailing zero padding to 94/56 ms. No upstream code is included with these assets.
