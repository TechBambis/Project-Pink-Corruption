# Frozen desktop speech: notices and source

The alpha freezes a **new clean CPython 3.12.13 environment**, installed from `packages/speech/desktop-build.lock`. It does not copy a developer virtual environment. `apps/desktop/speech.spec` and `scripts/freeze-desktop-speech.py` build a console one-folder service on the actual target. The existing Kokoro renderer and streaming worker remain separate service modes. Retained installed dependency metadata/license directories are shipped in `resources/notices/speech-metadata`.

The TTS service contains GPL-3.0-or-later phonemizer and eSpeak NG; its HTTP/PCM boundary does not remove those obligations. **Their source is included with the binary**, not deferred to an unfulfilled offer. Exact source URLs, byte counts and SHA-256 are in `config/desktop-speech-sources.json`; the assembled package retains the checked archives and manifest under `resources/notices/speech-source`. These are third-party public sources, independent of the matching application source archive.

The loader's 0.2.4 source commit is `146599e29be31bf17d99f0bcb7dbb2f92aef3d95`, with eSpeak NG submodule commit `4870adfa25b1a32b4361592f1be8a40337c58d6c`. Unpack the matching eSpeak source as the loader source's `espeak-ng` directory, then use the retained loader build scripts and platform workflow. Phonemizer 3.4.0 is supplied as its PyPI source distribution. The Python 3.12.13 and PyInstaller 6.22.3 source archives retain their license/build instructions; PyInstaller's bootloader exception remains intact. Preserve all third-party copyright notices.

To rebuild the service, create a clean native CPython 3.12.13 virtual environment at `.runtime/alpha-freeze-env`, install the desktop build lock, and run that environment's Python on `scripts/freeze-desktop-speech.py`. All installed package versions are recorded in the build lock; native target ABI and hashes are recorded in the assembled runtime manifest. Models are separately downloaded and verified by Setup; their upstream attribution is in `LOCAL_AUDIO_LICENSES.md` and the pinned model manifest.

The Linux slice relies on normal system glibc, libstdc++, libgcc and libgomp. It excludes accidentally discovered host eSpeak/audio libraries and does not redistribute those host libraries. The checksum-verified Ollama archive contributes the selected native llama executable/CPU/Vulkan libraries and retained upstream notices. No daemon, CUDA stack or global model management is included.
