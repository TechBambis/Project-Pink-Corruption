# Linux x64 packaging smoke

This maintainer build packages the existing player and Studio UI, a sandboxed Electron shell and a separate Node backend. It is the first packaging milestone, not a qualified local AI release. AI, speech, microphone recognition, devices, online media and imported-media analysis are unavailable. No model weights or private audio are included.

Build on Linux x64 with Node and npm: `npm ci`, `npm run prebuild`, `npm run desktop:build`. Electron 44.5.1, electron-builder 26.15.3, standalone Node 24.18.1 and tsx 4.20.6 are pinned. The build verifies the downloaded Node archive hash, rebuilds the web app, stages an allowlist and includes matching source from the current working tree. Build tools are only needed to rebuild, not to run the package. Network access is needed to install dependencies and obtain the pinned runtimes. No purchase, upload or publication occurs.

Artifacts are in `dist/desktop`: an AppImage, a tar.gz fallback, a matching source archive, a runtime manifest and SHA256SUMS. Verify with `sha256sum -c SHA256SUMS`. Extract the tar.gz into a directory outside this repository and run `./bambi-local-smoke`. Run the AppImage with `chmod +x` followed by its path; if FUSE is unavailable, use its `--appimage-extract` facility and launch `squashfs-root/AppRun`, or use the tar.gz. The package is unsigned. Its reviewed AppRun launcher preserves the renderer sandbox; sandbox failures are not bypassed with `--no-sandbox`. Hashes establish integrity against your reviewed copy; they do not provide OS publisher trust.

Default data location: `$XDG_CONFIG_HOME/bambi-local-smoke` (normally `~/.config/bambi-local-smoke`). An isolated run can use `./bambi-local-smoke --bambi-user-data='/absolute/path/Smoke user data'`. Start from any directory. Immutable resources remain inside the extracted app; preferences/history/SQLite are in `data`, Chromium state in `browser`, temporary loader files in `cache`, and the most recent backend log in `logs`, inside the selected user-data directory. The launcher creates private directories and the backend uses a private umask. SQLite data is not application-encrypted. Deleting/replacing the executable does not delete user data. No database downgrade/update compatibility is qualified yet.

Choose **Load offline sample**, then **Start**. The original synthetic chime sample uses the normal file player. Verify Pause/Resume, seek, Audio Mute/Unmute and volume. Press Escape twice for End session, which stops current playback/work and releases capture. Audio Mute silences output. Mic Mute stops capture; recognition is disabled in this smoke package. Quit from the application menu or Ctrl+Q exits the window and owned backend. Closing the last window also Quits on this Linux target. Open again to verify saved preferences. A second launch with the same user-data directory focuses the existing instance.

The backend binds only to `127.0.0.1:6969` and keeps the existing Host/Origin checks. A conflicting listener is not reused or killed. After the visible startup failure, Quit and retry with `--bambi-port=6970`. The launcher checks process ID, a private per-launch instance challenge, service identity and protocol before opening the UI. It does not discover ports, automatically restart services or run a tray daemon. A Node supervisor owns the backend process group; IPC disconnect after forced Electron termination triggers bounded shutdown. A failed backend requires Quit and reopen, retaining data.

The renderer has sandboxing, context isolation and no Node integration or native IPC bridge. Microphone/camera and other permission requests are denied for this milestone. Renderer requests are limited to this app's loopback origin and local blob/data resources. External links/new windows are not enabled. The build guide and corresponding source are accessible at `/desktop-guide.html` and `/corresponding-source.tar.gz` on the app origin. Retained runtime, application and dependency notices are in `resources/notices` and dependency package directories; Electron ships its own LICENSE and Chromium notices. The exact source digest and dependency inventory are recorded in RUNTIME-MANIFEST.json.

Run `npm run desktop:smoke -- /absolute/path/to/extracted/bambi-local-smoke` for the actual packaged runtime check. Maintainer automation uses Playwright installed in this checkout to inspect the received executable; the executable itself receives a PATH with no Node, Python, npm, Git or compiler tools. Test evidence is written to an isolated directory outside the repository. The internal release record records the actual tested reference environment, artifact checksums, controls, reopen, process cleanup and remaining limitations. A successful build alone is not runtime qualification. Windows, macOS, local AI/speech and a clean second physical machine remain later gates.
