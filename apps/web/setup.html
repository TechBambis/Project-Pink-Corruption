Choose your setup

Cloud text: configure the server connection once, then select Cydonia in the main app. Voice and microphone can be added separately.

Local text: use a compatible installed Ollama or native model. Your conversation stays on this machine.

Voice: Kokoro renders speech locally. Whisper handles microphone transcription locally.

Media only: your files and timeline can run without AI.

Open your companion

First run on Linux

From the repository root:

npm run setup
npm start

For a cloud connection, copy .env.cloud.example to .env.cloud and fill in the server URL, served model ID and API key. Restart the local app after changing it.

The key is read only by the local server. It is never sent to the browser. This page does not create or pay for GPU resources.

Optional local services

./scripts/setup.sh
./scripts/setup-local-tts.sh

Native model and Whisper preparation vary by hardware. See the README for the supported development setup. A desktop installer is not included in this release.
